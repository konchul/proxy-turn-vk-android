Country flag artwork from Apple Color Emoji © Apple Inc. This build uses
flag bitmaps extracted from the macOS 27.0 artwork in the following release.
The bitmaps are centered on 64 px transparent canvases and named by country code.

Source: https://github.com/xKleja/apple-fonts-on-windows-11/releases/tag/v1.3.0
Apple Color Emoji source build listed by the release: macOS 27.0 (26A5425a).

The legacy SU flag artwork is from EmojiTwo, originally released as EmojiOne
2.2 by Ranks.com, with contributions from the EmojiTwo community. The PNG
artwork is used unmodified and renamed by country code.

Source: https://github.com/EmojiTwo/emojitwo/tree/311eff547b3ff4a61fdbae897dd09d41416048fc
